# Последняя ночь — кооператив

Готовая браузерная 3D-игра: одиночный режим и совместное выживание до четырёх человек. Играйте прямо в браузере без регистрации.

**[Открыть игру](https://dead-signal-coop.onrender.com)**

## Как играть с друзьями

1. Откройте сайт и нажмите «Играть с друзьями».
2. Введите позывной и создайте комнату.
3. Скопируйте приглашение и отправьте друзьям.
4. Друзья вводят позывные и присоединяются. Когда все в комнате, создатель нажимает «Начать вылазку».
5. Переживите пять общих волн. Между волнами каждый выбирает своё улучшение.

WASD или стрелки — движение; мышь — прицел; ЛКМ — огонь; R — перезарядка; пробел или Shift — рывок. Подойдите к упавшему товарищу и удерживайте E 2,5 секунды, чтобы поднять его. На телефоне доступны джойстик и кнопки, прицеливание автоматическое.

В кооперативе меню паузы не останавливает сервер: персонаж остаётся на карте. Во время перерыва между волнами все игроки защищены. Если участник не выбирает улучшение, через 40 секунд сервер выбирает первое из предложенных.

## Локальный запуск

Нужен Node.js 22 или новее.

```sh
npm install
npm start
```

Откройте http://localhost:8787. Для теста нескольких игроков используйте разные вкладки. Для локальной сети откройте IP компьютера с портом 8787 на втором устройстве. Ссылка localhost работает только на том же компьютере; для друзей через интернет нужен хостинг.

```sh
npm test
```

## Размещение на Render

Этот архив содержит весь проект для размещения в аккаунте владельца. Требуется подключение Render и доступный ему репозиторий с этими файлами.

- Тип: Web Service
- Runtime: Node
- Plan: Free
- Build Command: `npm install --omit=dev`
- Start Command: `npm start`
- Health Check: `/health`
- `PORT` задаётся хостингом автоматически.

В корне есть `render.yaml` для размещения через Blueprint. Сайт и сервер работают на одном адресе; браузер автоматически выбирает защищённое соединение `wss` при HTTPS. Покупать домен для адреса `*.onrender.com` не нужно.

Бесплатный сервер может засыпать после простоя; первый запуск займёт дополнительное время. Комнаты хранятся в памяти и исчезают при перезапуске сервера. Существуют лимиты бесплатного тарифа: https://render.com/docs/free

## Устройство проекта

`public/` — вся графика и интерфейс, включая автономный одиночный режим.
`server/` — общий игровой сервер и расчёт боя.
`test/` — автоматические проверки сервера, сетевых подключений и клиента.

Сервер считает движение, попадания, здоровье, зомби, награды и волны. Комнаты имеют случайные коды; вместимость ограничена четырьмя игроками. После обрыва связи клиент пытается вернуться к тому же персонажу, пока его место удерживается сервером (45 секунд). Вход новым игрокам после старта партии закрыт. При уходе создателя его роль переходит следующему подключённому игроку. Дружественный огонь выключен.

Графика и звук создаются программно. Three.js и ws используются по лицензии MIT; лицензия Three.js находится в `public/vendor/THREE-LICENSE.txt`, лицензия ws устанавливается вместе с пакетом.
